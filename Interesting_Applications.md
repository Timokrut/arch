# xdotool
`xdotool` - утилита для управления окнами X11 и имитации действий пользователя: нажатий клавиш, кликов мыши, перемещения окон и т.д.

Найти окно:
```bash
xdotool search obsidian
```

Получить ID активного окна:
```bash
xdotool getactivewindow
```

Отправить нажатие клавиши:
```bash
xdotool key h
```

Переместить мышь:
```bash
xdotool mousemove 500 300
```

Нажать левую кнопку мыши:
```bash
xdotool click 1
```

# fakeroot
`fakeroot` - создаёт окружение, в котором программы видят поддельные права и владельцев файлов. При этом реальные root-привилегии пользователю не выдаются. Часто используется при сборке пакетов.
```bash
fakeroot makepkg
```
Важно: `fakeroot` не является способом получить root-доступ. Он только имитирует некоторые операции с правами файлов.

# feh
`feh` - очень лёгкий просмотрщик изображений.


# redshift
`redshift` - изменяет цветовую температуру экрана в зависимости от времени суток. Вечером делает изображение более тёплым.
```bash
redshift -l 59.93:30.31 -m vidmode
```

Установить конкретную температуру:
```bash
redshift -O 3500
```

Вернуть стандартную температуру:
```bash
redshift -x
```

# ffmpeg
`ffmpeg` - мощная консольная утилита для работы с аудио и видео.

Извлечь аудио из видео:
```bash
ffmpeg -i video.mp4 audio.mp3
```

Конвертировать видео:
```bash
ffmpeg -i input.mkv output.mp4
```

Обрезать видео:
```bash
ffmpeg -i input.mp4 -ss 00:01:00 -t 00:00:30 output.mp4
```

Изменить разрешение:
```bash
ffmpeg -i input.mp4 -vf scale=1920:1080 output.mp4
```

Посмотреть информацию о медиаданных:
```bash
ffprobe video.mp4
```

`ffmpeg` умеет работать с кодеками, контейнерами, потоками, субтитрами, фильтрами и многим другим.

# xclip
`xclip` - утилита для работы с буфером обмена в X11 из терминала

Скопировать текст:
```bash
echo "hello" | xclip -selection clipboard
```

Скопировать содержимое файла:
```bash
xclip -selection clipboard < file.txt
```

Получить содержимое буфера:
```bash
xclip -selection clipboard -o
```

# tmux
`tmux` - терминальный мультиплексор. Позволяет создавать несколько терминальных окон внутри одной сессии и сохранять процессы после отключения SSH.

Запустить:
```bash
tmux
```

Создать именованную сессию:
```bash
tmux new -s server
```

Посмотреть существующие сессии:
```bash
tmux ls
```

Подключиться к сессии:
```bash
tmux attach -t server
```

# yt-dlp
`yt-dlp` - консольная утилита для скачивания видео и аудио с YouTube и множества других сайтов.

Скачать видео:
```bash
yt-dlp "https://youtube.com/..."
```

Скачать только аудио:
```bash
yt-dlp -x "https://youtube.com/..."
```

Посмотреть доступные форматы:
```bash
yt-dlp -F "https://youtube.com/..."
```

Скачать конкретный формат:
```bash
yt-dlp -f 137+140 "https://youtube.com/..."
```

# jq
`jq` - утилита для обработки JSON из терминала.

```bash
echo '{"name":"Tim","age":20}' | jq

{
  "name": "Tim",
  "age": 20
}
```

Выввести информацию по ключу:
```bash
echo '{"name":"Tim","age":20}' | jq '.name'

"Tim"
```

# nmap
`nmap` - утилита для исследования сети и проверки доступных портов.

Проверить собственный сервер:
```bash
nmap localhost
```

Проверить конкретный хост:
```bash
nmap 192.168.1.1
```
